# 实时频谱（Music Spectrum Pro）

捕获电脑正在播放的声音，提供 **柱状 / 曲线 / 雾状** 三种可视化，顶部按钮一键切换。
本地播放器、QQ 音乐、浏览器网页音乐等任何从扬声器输出的声音都能识别。

## 三种视图

| 视图 | 说明 |
|---|---|
| 柱状频谱 | 96 根对数频率柱（低频→高频），带白色峰值帽与平滑衰减，蓝青渐变到红 |
| 曲线频谱 | 各频段电平连成一条平滑曲线，下方带面积填充 |
| 雾状频谱 | 每段频段由外层薄雾、中层雾、内核光带与顶部光晕多层叠加，呈弥散云雾效果 |

## 功能特点

- **系统声音环路捕获**：WASAPI loopback 录制扬声器输出，不依赖麦克风；
  找不到 loopback 时兜底“立体声混音”。
- **自动音量平衡（AGC）**：动态跟踪近期响度，配合动态范围压缩与顶部封顶，
  大音量音乐不会全部贴顶，小音量也能看清起伏。
- **低频无空缺**：按 FFT 频点索引映射频段，孤立空柱由邻柱插值兜底。
- **多输出设备自动回退**：当前设备持续约 4 秒检测不到声音时，自动切换到下一个候选设备；
  **程序不会因音乐停止而自动退出**，关闭窗口才结束。
- **静默启动**：双击 `启动频谱.bat` 经 VBS 调用 `pythonw.exe` 运行，不弹出黑色 cmd 控制台窗口。
- **轻量简洁**：仅依赖 numpy + pyaudiowpatch，界面为 Python 自带 tkinter；
  关闭窗口即释放音频设备、程序完全退出，**不驻留后台、不写开机自启项**。

## 环境要求

- Windows 10 / 11
- Python 3.9 及以上（本机使用 D:\Python39，启动器调用其 `pythonw.exe`）

## 安装依赖（首次运行）

```bat
D:\Python39\python.exe -m pip install -r requirements.txt
```

## 运行方式

- 双击 `启动频谱.bat`（静默启动，不弹黑窗）；或
- 调试时在本目录执行（带控制台，便于看报错）：

```bat
D:\Python39\python.exe main.py
```

打开后点击顶部按钮切换视图，播放任意歌曲即可看到对应动态效果。
状态栏显示当前输入设备、采样率与视图名称；没有声音时显示等待提示，程序保持运行。

## 工作原理

1. `audio_capture.py` 枚举 WASAPI 设备，打开默认扬声器对应的 `[Loopback]` 环路设备，
   后台线程持续读取音频块并转为单声道；静音时自动回退到其他候选设备。
2. `spectrum.py` 加 Hann 窗后做 FFT，按频点索引映射到对数频段；AGC 跟踪峰值电平做动态归一化，
   经伽马压缩、顶部封顶、时间平滑与峰值保持，得到 0~1 的柱高。
3. `gui.py` 每 30ms 取最新音频块分析：柱状直接绘制柱体与帽；曲线连成平滑折线并填充；
   雾状按频段叠加多层不同透明度的色带与顶部光晕。

## 可调参数

- 柱数 / 频段：`gui.py` 中 `SpectrumAnalyzer(n_bars=96)`，或 `spectrum.py` 的 `freq_min / freq_max`。
- 音量平衡：`spectrum.py` 的 `dyn_range_db / gamma / ceiling / decay`。
- 雾状层次与浓度：`gui.py` `_draw_fog` 中的三层宽度系数（1.7 / 1.15 / 0.6）与透明度（0.16 / 0.34 / 0.75）。

## 常见问题

- **频谱不动 / 提示等待音乐**：确认电脑正在出声；程序约 4 秒检测不到声音会自动切换设备，
  可看状态栏设备名。若有多个输出设备（显示器耳机、蓝牙音箱），把声音从状态栏所示设备播放，
  或在 Windows 声音设置里把实际出声设备设为默认输出。
- **双击 bat 没反应**：静默启动不显示控制台；若依赖未装会直接退出。先按上面的调试命令
  `D:\Python39\python.exe main.py` 运行一次查看报错。
- **找不到捕获设备**：声卡驱动未提供 loopback / 立体声混音；可在声音设置启用“立体声混音”，
  或更新声卡驱动后重试。

## 隐私与自启说明

- 程序只在本机分析音频电平，**不录音、不保存音频文件、不上传数据**。
- 程序为手动启动，未注册任何开机启动项；关闭窗口后进程即结束，无后台服务。
